# 丰台区项目全周期跟踪平台（手机端）需求文档

- 日期：2026-08-20
- 来源：原型 `D:\fengtai\丰台手机端0819li`（Axure 导出，63 页）
- 状态：原型分析 → 业务需求

## 1. 系统概述

**丰台区项目全周期跟踪平台**——面向土地/规划项目的移动端全周期管理。覆盖项目从立项、征地、供地到建设、核验的完整生命周期，支持进展录入、流程跟踪、问题上报与协助、数据监测。

与 `fengTaiSysView` 基座的关系：本原型是该基座的**业务化蓝本**。基座已具备通用 RBAC、节点动态表单、PC+移动双端，本需求将其语义化为"土地项目全周期业务"。

## 2. 业务模型

两条主业务线 + 横向能力：

```
一级开发（政府主导，供地前）
  项目立项 → 编制详细规划稳定用地指标 → 土地一级开发实施方案审批
  → 授权委托 → 用地及规划审核意见函 → 征地前准备 → 征地 → 征地结案

二级开发（供地后建设）
  供地前准备 → 多规合一初审 → 用地预审与选址意见 → 多规合一会商
  → 项目立项 → 土地供应（划拨 / 协议出让 / 招拍挂）
  → 建设工程规划许可 → 全过程监督 → 规划核验 → 其他

横向能力：项目查询、进展录入、流程查看、问题上报/协助、监测统计、授权委托
```

### 2.1 关键流程示例

**征地（15 步）**：征地申请 → 土地征收启动预公告编制 → 发布预公告(一) → 土地现状调查 → 社会稳定风险评估及备案 → 编制补偿安置方案并征求意见 → 区政府审批 → 确定减量地块 → 规划图/三区三线校核 → 发布补偿安置公告(二) → 签订补偿安置协议 → 村民代表大会 → 成片开发方案 → 区级专家评审 →（结案）

**供地前准备**：权属审查 / 交评 / 场评 / 地上物拆迁 / 市政拆迁 / 二级钉桩（各节点带日期、办理中/已完成状态）

**全过程监督**：正负零 → 灰线 → 结构封顶 → 竣工

**土地供应方式**：划拨、协议出让、招拍挂

## 4. UI 框架（手机端）

```
┌──────────────────────────────┐
│ < 丰台区项目全周期跟踪平台     │  顶部返回栏 + 标题
│ [搜索项目/土地]              │  搜索框
│  一级开发 3/8  二级开发 3/4   │  统计卡片（完成数/总数）
│  项目总览 6 13               │
│  一级开发项目 / 二级开发项目   │  业务入口
│  公共公益类 / 完善没收建筑...  │
├──────────────────────────────┤
│ 项目卡片：[项目名]  【进行中】 │  列表卡片 + 状态 tag
│  建设单位 / 项目位置          │
│  用地规模 / 建筑面积          │
│  项目阶段：土地供应>资产出库   │  阶段路径
│  [进展录入][流程查看][问题查看]│  操作按钮
├──────────────────────────────┤
│  首页    监测    我的    进度  │  底部 4-tab
└──────────────────────────────┘
```

- **列表筛选**：全部/进行中/已完成；一级/二级分类带计数（16/6/4）
- **流程页**：横排节点流程图，节点带编号+日期+状态（办理中/已完成），可录入/编辑
- **录入**：分步表单（"下一步"）
- **问题**：环节名称/提出部门/提出日期/问题描述/解决情况

## 5. 业务表单与字段

| 环节 | 表单要素 |
|---|---|
| 多规合一初审 | 初审意见、未通过、是/否、已完成/部分完成、提交 |
| 征地结案申报 | 征地结案表、结案证明（附件）、全部/部分、是/否、提交 |
| 划拨/出让/招拍挂录入 | 项目信息（建设单位/位置/用地规模/建筑面积）、项目阶段 |
| 问题协助 | 环节名称、提出部门、提出日期、问题描述、解决情况（已解决/部分解决/再商议/搁置） |
| 供地前准备/监督节点 | 各节点独立表单：日期、办理中/已完成、录入/编辑 |

- 表单控件模式：输入框、数字、日期、单选（是/否）、多选状态（全部/部分）、附件上传（证明/公示）、提交/下一步
- **与基座映射**：上述每种"环节表单"= fengTaiSysView 的一个"填报节点"（字段由节点管理配置），无需写死页面

## 6. 问题协助闭环

- 任意流程节点可发起问题：环节名称 + 提出部门 + 日期 + 问题描述
- 解决状态四态：**已解决 / 部分解决 / 再商议 / 搁置**
- 有"问题协助记录"列表，问题编号（40/50）计入监测

## 7. 监测统计（项目监测页）

- 分类：开发项目 / 公共公益类项目补办手续 / 自然资源违法立案查处 / 完善没收建筑产权手续
- 指标：本年度数量、同比、环比；供地方式分布（招拍挂/协议出让/划拨）
- 统计卡：问题（40/50）、业务量（300/500）

## 9. 落地建议（按现有基座）

1. **数据模型扩展**：`NodeItem` 升级为"流程节点"——增加 `projectId`（所属项目）、`step`（顺序）、`status`（办理中/已完成）、`date`；新增 `ProjectItem`（项目主数据）、`IssueItem`（问题）。
2. **节点管理升级**：节点配置增加"挂项目 + 流程顺序"，字段配置沿用现有 FieldConfig。
3. **填报扩展**：从"仅提交"升级为"记录列表 + 编辑"，同节点多次录入（进展录入）。
4. **新增页面**：项目查询（列表+筛选）、流程查看（横排节点图）、问题上报/协助记录、项目监测统计。
5. **移动端**：沿用 mobile/ 架构，TabBar 调整为"首页/监测/我的/进度"，列表卡片 + 流程视图在移动端实现。
6. **权限**：角色→可见项目/节点，沿用现有 RBAC。
